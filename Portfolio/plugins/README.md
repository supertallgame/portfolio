# Minecraft Plugin Portfolio

| Plugin | What it shows off |
|--------|-------------------|
| CoreEconomy | Persistence, commands, GUI inventories, config-driven data |
| HomeHub | Permissions, scheduler, cooldowns, event cancellation, async teleports |
| DailyQuests | Event tracking, per-player state, daily resets, cross-plugin rewards |

Each folder is a standalone Maven project. Build any of them with `mvn clean package`.
Requires Java 21 and a Paper 1.21+ server.
